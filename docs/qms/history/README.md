# Historical audit implementation reports

These reports preserve the earlier investigation and design work. They describe
the application at the time they were written; their pending-work lists are not
the current implementation status.

The current repair is documented in [Audit workflow repair](../audit-workflow-repair.md).
Runtime logs, browser recordings, screenshots and duplicated source archives
have been removed from the repository. New verification output belongs in the
ignored `.artifacts/` directory.
