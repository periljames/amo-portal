# Procurement Alert Semantics

- **Success**: a controlled action committed successfully. Green visual cue and an ascending audio cue when audio feedback is enabled.
- **Warning**: action completed with an operational constraint, or attention is required. Amber visual cue and repeated attention tone.
- **Error**: action failed or backend validation blocked it. Red visual cue, assertive live-region announcement and descending error tone.
- **Information**: non-critical state or download activity. Blue visual cue; silent by default.

AOG demand, active Quality holds and blocked actions use danger treatment. Quarantined receipts, restricted suppliers, pending verification and variances use warning treatment. Audio remains controlled by the existing notification preference.
